## Snapshot

USGS states that USGS-authored or produced data and information are in the
United States public domain and asks users to provide proper credit. The same
page warns that some third-party website images or materials can have different
rights. This adapter stores only the official catalog JSON record and does not
copy website images or third-party media.

The ingestion code stores a SHA-256 hash of this snapshot on each immutable
source release. A later terms change must create a new reviewed snapshot; it
must not rewrite an existing release record.
